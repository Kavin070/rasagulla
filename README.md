# Anniversary Website 💗

## Customize (2 minutes)
1. Open `index.html` in any text editor (VS Code / Notepad).
2. Edit the block marked "EDIT THIS PART": her name, your name, the date you got together, the letter, the story, and the reasons.
3. Add photos to the `photos/` folder named `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg` (they show up in "Our little story"; no photo = emoji shows instead).
4. Double-click `index.html` to preview it.

## Deploy (pick one, all free)
**Netlify Drop (easiest):** go to app.netlify.com/drop, drag this whole folder in, and you get a link. Rename the site in Site settings for a cute URL.
**GitHub Pages:** create a repo, upload these files, then Settings > Pages > Deploy from branch (main, root). Link: https://YOURNAME.github.io/REPO/
**Vercel:** vercel.com > Add New > Project > upload the folder, or run `npx vercel` inside it.
